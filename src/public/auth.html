Setup Instructions

  1. Complete the authentication process above
  2. For Cursor IDE: Go to Settings > API Keys
  3. In the "Override OpenAI Base URL" section, enter: http://localhost:3000/openai/v1 (legacy/experimental; not equivalent to the Claude Code integration).
  4. For Claude Code: Add to .claude/settings.local.json: 
    {
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:3000",
    "ANTHROPIC_AUTH_TOKEN": "sk-dummy",
    "ANTHROPIC_MODEL": "sonnet"
  }
}
  5. If the proxy has PROXY_AUTH_TOKEN configured, replace sk-dummy in ANTHROPIC_AUTH_TOKEN with that value. Use it as Cursor's API key too. Never put the token in a URL.
  6. Start using Cursor IDE or Claude Code with GitHub Copilot!
